# 📚 Mercadinho da Esquina

## 🧾 Descrição
Esta aplicação é uma API desenvolvida para simular o **controle de estoque** de um **mercado de pequeno porte**.  
Ela permite o cadastro e gerenciamento de produtos, fornecedores e pedidos de compra, facilitando a organização dos itens disponíveis e o controle de entradas e saídas de mercadorias.  
Ideal para uso em pequenas mercearias que buscam uma solução simples e eficiente para manter o estoque atualizado.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** C# (.NET 8)  
- **Framework:** ASP.NET Core - Minimal API  
- **ORM:** Entity Framework Core  
- **Banco de Dados:** SQLite  
- **Front-end:** JavaScript  
- **Versionamento:** Git + GitHub  

## 🚀 Como Executar o Projeto

### ✅ Pré-requisitos
- [.NET SDK 8.0+](https://dotnet.microsoft.com/en-us/download)
- SQLite (ou algum cliente de visualização como [DB Browser for SQLite](https://sqlitebrowser.org/))
- Git instalado
