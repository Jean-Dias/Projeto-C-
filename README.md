## 🧾 Descrição

Este projeto consiste no desenvolvimento de uma **Minimal API RESTful** utilizando C# e .NET Core, com persistência de dados via **SQLite** e comunicação em formato **JSON**.  
O objetivo é simular o controle de estoque de uma empresa, permitindo cadastrar, consultar, editar e remover produtos, fornecedores e movimentações de entrada e saída de itens.

Este repositório está vinculado a uma atividade prática e acadêmica, desenvolvida em dupla, com versionamento completo e histórico de desenvolvimento registrado por meio de **Pull Request**.
